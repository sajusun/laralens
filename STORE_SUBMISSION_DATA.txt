2. DETAILED DESCRIPTION (MARKDOWN & TEXT COMPATIBLE)
--------------------------------------------------------------------------------
Copy and paste the text below into the "Detailed Description" field on Microsoft Partner Center:

Stop digging through native browser DevTools just to find CSRF tokens, session cookies, Inertia props, or backend routes.

LaraLens is the ultimate browser developer toolkit engineered specifically for Laravel, Inertia.js (Vue/React), and modern full-stack web developers. It automatically detects Laravel applications on your active tab and delivers an instant 1-click inspection dashboard.

Key Features & Capabilities:

1. 🛡️ Authentication & CSRF Hub
• Instant Token Extraction: Reads meta csrf-token, XSRF-TOKEN cookie, and laravel_session cookie simultaneously.
• Bearer Token Scanner: Detects active Sanctum and JWT API tokens from local storage.
• 1-Click cURL & Postman Exporter: Instantly copy complete terminal cURL commands or formatted Postman Bulk Edit JSON headers with active session cookies and CSRF headers.
• 🧹 1-Click Session Reset: Clear Laravel session cookies and reload the tab with one click to test guest views or expired session workflows.
• Authenticated User Card: View the current logged-in user profile extracted directly from shared Inertia props.

2. ⚡ Inertia.js Props Explorer
• Component Inspector: Identifies active page components (e.g., Pages/Dashboard, Auth/Login).
• Validation Errors & Flash Callout: Prominently highlights validation errors and flash notifications so you immediately know why form submissions failed.
• Categorized Props Tree: Switch between Page Props, Shared Props, and Raw Payload.
• Real-Time Search: Filter props by key name or JSON value instantly.
• 1-Click Export: Copy entire props trees to clipboard for fast debugging.

3. 🗺️ Ziggy Routes Navigator
• Zero-Terminal Route Discovery: Inspect all registered routes directly from window.Ziggy without running artisan commands.
• Method Filtering: Filter routes by GET, POST, PUT, PATCH, and DELETE.
• Instant Search: Real-time search by route name (e.g., users.create) or URI (e.g., /api/orders).
• Quick Code Snippets: 1-click copy for Route URI, Ziggy route() helper, or Inertia router.visit() call.

4. 🌐 Built-in Quick API Tester
• Test Laravel endpoints directly from the extension popup.
• Automatically attaches current tab XSRF-TOKEN, laravel_session, and Accept: application/json headers.
• Request Body Editor: Built-in JSON body editor with automatic syntax prettification for POST, PUT, and PATCH requests.
• Live Response Inspector: View HTTP response status codes, latency timings, and formatted JSON output.

Privacy & Security Guarantee:
LaraLens operates 100% client-side inside your local browser. It does NOT track, harvest, collect, or transmit any cookie values, URLs, or browsing data to any external server.

5. PERMISSIONS JUSTIFICATION (FOR STORE REVIEWERS / CERTIFICATION NOTES)
--------------------------------------------------------------------------------
When Microsoft Edge Partner Center asks why the extension requests permissions, copy and paste these justifications:

1. activeTab:
"Required to inspect the DOM of the active tab only when the developer clicks the LaraLens extension icon, allowing extraction of the CSRF meta tag and Inertia page data."

2. cookies:
"Required to read local Laravel session cookies (XSRF-TOKEN and laravel_session) strictly on the active domain for generating local development cURL/Postman test headers and enabling the 1-click developer session reset feature."

3. storage:
"Used exclusively for storing developer UI preferences locally within the browser (such as active tab view, filter preferences)."

4. scripting:
"Required to inject a lightweight, non-destructive bridge script into the active page context to read window.Ziggy routes and window.__page Inertia properties."

5. host_permissions (http://*/*, https://*/*):
"LaraLens is a developer inspection utility that must operate across local and remote development environments where Laravel applications run. Developers frequently host their applications on custom local hosts, including http://localhost:*, http://127.0.0.1:*, http://*.test, http://*.local, and custom staging/production subdomains. Broad host permissions are required solely so the extension can detect Laravel apps across custom local developer ports and domains. No network traffic is intercepted or monitored."
