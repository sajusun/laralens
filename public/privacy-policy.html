🔍 LaraLens Privacy Policy 100% Client-Side

Effective Date: October 28, 2026 • Developer: Sakhawat Hossain • GitHub Repository
🔒 Zero-Tracking Guarantee: LaraLens operates entirely within your browser's local sandbox. It does not collect, store, transmit, log, or sell any personal data, cookie strings, or network payloads.

1. Overview

LaraLens is an open-source browser developer extension created to help Laravel and Inertia.js developers inspect local CSRF tokens, session cookies, Inertia page props, and Ziggy backend routes with one click.

2. Data Handled by the Extension

  • Session Cookies (laravel_session, XSRF-TOKEN): Read locally strictly on the active tab via the chrome.cookies API to display formatted cURL and Postman testing headers. Data never leaves your machine.
  • Page DOM & Scripts (window.Ziggy, window.__page): Scanned temporarily in memory on the active tab to render the route table and component props.
  • Local / Session Storage: Read locally for Sanctum or JWT bearer tokens to populate the auth tester.
  • API Tester: All test requests are initiated directly from your local browser to your application server. No remote proxy or logging servers are used.

3. Permissions & Technical Justification

Permission Technical Reason
activeTab Accesses active tab DOM when the user clicks the extension popup.
cookies Extracts XSRF-TOKEN and laravel_session to generate testing headers and allow developers to clear local session cookies.
storage Locally caches developer preferences (active tab filter, view preferences).
scripting Injects a lightweight bridge to inspect page-level variables (window.Ziggy, window.__page).
host_permissions Allows the tool to inspect local development domains (http://localhost:*, http://*.test, http://*.local) and staging/production apps.

4. Third-Party Trackers & Analytics

LaraLens contains zero third-party trackers, zero external advertising libraries, and zero telemetry analytics. All extension logic is fully bundled in compliance with Manifest V3 rules.
